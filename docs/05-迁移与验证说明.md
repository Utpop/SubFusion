## 2. 配置与数据兼容性

| 项 | 兼容性 |
| --- | --- |
| 配置文件路径 | **完全相同**：`%USERPROFILE%\.subtitle_merger.json` |
| 文件格式 | UTF-8 无 BOM、`indent=2`、中文不转义；未知键保留并写回 |
| 19 个键名 | `ffmpeg, ffprobe, container, mode, vcodec, acodec, crf, preset, workers, suffix, outdir, keep_existing_subs, keep_metadata, convert_encoding, hard_multi, verify, threshold, recursive, last_dir` — 全部一致 |
| 数值类型 | `crf / workers / threshold` 仍以**字符串**写入；布尔值为 JSON 布尔 |
| `overwrite` | 与 Python 版一致，**不持久化**（每次启动回到 `true`） |
| 读取方向 | C# 可直接读 Python 写出的配置；Python 亦可读 C# 写出的配置 |
| ffmpeg / ffprobe 定位 | 顺序不变：配置 → 环境变量 → 程序目录 / `bin` → PATH → `C:/ffmpeg/bin`、`D:/ffmpeg/bin`、`C:/Program Files/ffmpeg/bin` |
| 输出文件命名 | `stem + suffix + .容器`、`same` 用源扩展名、同名冲突加 `_sub`，规则不变 |
| 报告 CSV | 9 列、UTF-8 BOM、CRLF、QUOTE_MINIMAL、`合并报告_YYYYMMDD_HHMMSS.csv`，字节兼容 |
| 临时字幕 | `<stem>_utf8<ext>` 与 `hardsub_<N><ext>` 命名规则不变 |

**升级建议**：从 Python 版迁移时无需改动任何配置或已生成的输出文件；直接运行 C# 版即可沿用上次的输出目录、编码器、阈值等设置。

## 3. 等价性验证方法

### 3.1 A 组：以 Python 版为基准的逐项比对

迁移验证期间，用原 `core.py` 直接生成了一份**冻结基准快照**：

`src/SubtitleMerger.SelfTest/Reference/reference.json`

覆盖：`formatDuration`、`formatSize`、`normalize`、`tokenize`、`detectLang`、`similarity`、`match`、`outputPath`、`commands`（9 组 ffmpeg 命令）、`progress`、`encodings`（7 组字幕字节流，Base64 编码）。

`SelfTest/Program.cs` 读取该 JSON，把 C# 实现的输出与之逐项比对（字符串精确相等、浮点近似相等、命令序列逐元素相等）。

> **重要**：这是 Python v1.1 行为的冻结快照，C# 版运行时**不依赖任何 Python 文件**。
> 删除 Python 源码后不能再从仓库重新生成；如需扩充用例，按同样 JSON 结构手工追加期望值即可。
> 快照文件本身随源码保留，以便日后回归比对。

### 3.2 B 组：真实 ffmpeg 端到端

`SelfTest` 在临时目录用本机 ffmpeg 生成 3 秒测试视频与字幕，然后跑通：

1. 软字幕内挂（MKV）→ ffprobe 验证「1 视频流 + 1 音轨 + 1 字幕轨」，并做输出校验（`verify_ok=True, issues=[]`）；
2. GBK 字幕编码识别为 `gb18030` 并转 UTF-8 无乱码；
3. 硬字幕烧录 → 输出无字幕轨、视频流仍在；
4. 取消行为 → 未开始的任务标「已取消 / 待处理」，不产生输出；
5. 日志分隔线、汇总统计、失败隔离等编排行为。

所有临时素材在结束时删除，不污染仓库。

### 3.3 C 组：GUI 启动冒烟

`App/App.xaml.cs` 提供 `--smoke`：窗口创建并激活 1.5 秒后写 `%TMP%/subtitle_merger_smoke.txt` 并以 0 退出。
该钩子能捕获「XAML 编译产物缺失 / 资源索引缺失 / 主窗口构造异常」这类只有真正启动才会暴露的问题（本次发布排查正是靠它发现 `.xbf`/`.pri` 未进发布目录）。

## 6. 已知约束与后续建议

1. **ffmpeg 未内置**：与原版相同，需目标机自带 ffmpeg/ffprobe（硬字幕需 libass）。
2. **发布目录必须整体拷贝**：`dist/SubtitleMerger/` 内含 XAML 编译产物与运行时，单独复制 exe 无法启动。
3. **目标平台**：Windows 10 1809+ / x64；不需要 .NET 运行时或 Windows App SDK 运行时预装（发布目录自带）。
4. **文件选择器**：WinUI 原生 picker 不支持任意 `initialdir`，首次选择落在系统默认位置，之后由 Shell 记忆。
5. **冻结基准**：`Reference/reference.json` 是 Python v1.1 行为的快照，扩充用例需按现有 JSON 结构手工维护。
6. **可选后续增强**（不影响本次等价性）：把 `CommunityToolkit.Mvvm` 升级并把字段式 `[ObservableProperty]` 改为 partial 属性写法；为字幕轨增加「启用」复选框；把日志改为虚拟化的大文本控件以支持超长日志。
