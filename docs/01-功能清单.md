## B. 核心逻辑功能点（`core.py` 37 个顶层函数 + 4 个类）

### B.1 配置与工具定位

1. `load_config()`（`85`）：读 `CONFIG_PATH`，UTF-8 + `json.load`；**任何异常静默返回 `{}`**。
2. `save_config(cfg)`（`93`）：`json.dump(cfg, ensure_ascii=False, indent=2)`，UTF-8 覆盖写；**异常静默 `pass`**。
3. `bundled_dir()`（`101`）：PyInstaller 单文件取 `sys._MEIPASS`；frozen 多文件取 exe 目录；源码运行返回 `None`。
4. `_locate(name, cfg_key)`（`111`）：候选顺序**严格固定** — 配置值 → 环境变量（`ffmpeg*` 读 `FFMPEG_PATH`，否则 `FFPROBE_PATH`）→ `bundled_dir()/`、`bundled_dir()/bin/` → 源码目录 `./`、`./bin/`、`./ffmpeg/bin/` → `shutil.which()` → Windows 常见位置 `C:/ffmpeg/bin`、`D:/ffmpeg/bin`、`C:/Program Files/ffmpeg/bin`。返回**第一个真实存在**的路径，否则 `None`。
5. `find_ffmpeg()` / `find_ffprobe()`（`146/150`）。
6. `ffmpeg_capabilities(ffmpeg)`（`154`）：分别执行 `-hide_banner -filters`、`-hide_banner -encoders`（各 30 秒，`stderr=STDOUT`）；返回 `{"libass": bool, "x264": bool, "x265": bool, "nvenc": bool}`；`libass` 用精确子串 `" subtitles "` 或 `"\tsubtitles "` 判断；异常吞掉保持 `False`。
7. `ffmpeg_version(ffmpeg)`（`182`）：`-version` 首行，`version.split(" Copyright")[0]` 在 GUI 日志中使用；超时 20 秒，异常返回 `""`。

### B.2 文件收集与自动匹配

8. `collect_files(paths, recursive=True)`（`198`）：返回 `(videos, subtitles, skipped)`。文件按扩展名分三类；目录递归用 `os.walk` 且 `dirs[:] = [d for d in dirs if not d.startswith(".")]` **跳过隐藏子目录**（隐藏文件不跳过），`sorted(names)` 保证顺序；非递归只取顶层 `os.path.isfile` 项；视频/字幕分别按 `abspath` 去重（`skipped` 不去重）；结果按路径 `lower()` 排序。
9. `strip_lang_tokens(tokens)`（`258`）：移除语言 token，**只保留第一个**命中的语言码，其余语言 token 直接丢弃；返回 `(剩余 tokens, lang|None)`。
10. `tokenize(name)`（`272`）：严格顺序 — 取 basename 去扩展名 → 去 `[] () {}` 内容 → `lower()` → `NOISE_RE` 替换空格 → 白名单正则替换空格 → `split()` 去空串。
11. `normalize_name(name)`（`285`）：`tokenize` → 去语言 token → 空格拼接。
12. `detect_lang_from_name(path)`（`290`）：优先语言标记；否则取**完整 basename（含扩展名、未 lower）**：假名 → `jpn` > 韩文 → `kor` > 汉字 → `chi` > `und`。
13. `similarity(a, b)`（`305`）：空串 → `0.0`；相等 → `1.0`；包含关系且 `len(short) >= 3` → `0.72 + 0.22 * min(1, ratio)`；否则 `difflib.SequenceMatcher(None, a, b).ratio()`（**`autojunk=True`**）。
14. `match_subtitles(videos, subtitles, threshold=0.72, one_sub_per_video=False)`（`320`）：每个视频初始空列表；逐条字幕取最高分视频（严格 `>` 更新，平局保留先出现者，`best_score` 初始 `0.0` 故 0 分不匹配）；`>= threshold` 才挂；`one_sub_per_video=True` 时若目标视频已有字幕则**直接放弃该字幕**（不找次优）；每视频字幕按路径 `lower()` 排序；`unmatched` 保持输入顺序。语言标记不参与打分，仅被剔除以免干扰。

### B.3 编码检测与转换

15. `_score_text(text, encoding)`（`391`）：取样前 4000 字；统计坏字符（`<0x20` 非 `\r\n\t`、`0x7F..0x9F`、`U+FFFD` 记 10 个）、CJK/假名/韩文；`score = -bad*5.0`；UTF-8 严格解码 `+30.0`；非 UTF-8 加 `cjk*0.35 + kana*0.4 + hangul*0.4`；有汉字时按简繁字频表给 `gb18030`/`big5` 加减分，假名给 `shift_jis`/`euc-jp` `+kana*0.5`，韩文给 `euc-kr` `+hangul*0.5`。
16. `_looks_like_utf16(raw)`（`439`）：前 4000 字节，长度 `<8` 或 `pairs<4` 放弃；偶位零比 `>0.55` 且奇位 `<0.15` → `utf-16-be`；反之 → `utf-16-le`；否则 `None`。
17. `detect_encoding(path, sample_size=262144)`（`462`）：BOM 顺序 **UTF-8 → UTF-32 LE → UTF-32 BE → UTF-16 LE → UTF-16 BE**（UTF-32 LE 与 UTF-16 LE 前缀相同，顺序不可换），返回 `("utf-8-sig"|"utf-32"|"utf-16", True)`；无 BOM 但 NUL 超阈值时启发式判 UTF-16；否则严格 UTF-8 解码成功即返回 `("utf-8", False)`；再对 6 个候选编码严格解码并打分取最高（严格 `>`，平局保留候选表先者）；全部失败回退 `("utf-8", False)`；读文件 `OSError` 亦回退。
18. `is_text_subtitle(path)`（`504`）：扩展名在 `TEXT_SUB_EXTS`。
19. `ensure_utf8(path, temp_dir, use_cache=True)`（`508`）：位图字幕原样返回 `(path, False, "")`；缓存 key `(abspath(path), abspath(temp_dir))`，**仅缓存确实生成临时文件的结果**；调用 `_convert_to_utf8` 返回 `(新路径, 是否创建, 原编码)`。
20. `clear_utf8_cache()`（`527`）：每轮批量结束 / 关闭窗口时清空。
21. `_convert_to_utf8(path, temp_dir)`（`532`）：已是干净 UTF-8 → 原路径；否则全文件读取 → `decode(encoding, errors="replace")`（`LookupError` 回退 UTF-8/replace）→ 有 BOM 时去 `\ufeff` → 写 `temp_dir/<stem>_utf8<ext>`（`encoding="utf-8"` **无 BOM**、`newline=""` 原样换行）；建目录/读/写 `OSError` 均回退原路径。
22. `prepare_hard_subs(tracks, work_dir, convert=True)`（`570`）：为规避 libass 在 Windows 上路径/冒号转义，复制到 `work_dir/hardsub_<index><ext>`（无扩展名用 `.srt`）纯 ASCII 文件名；`convert=True` 且为文本字幕时按检测编码解码、去 `\ufeff`、写 UTF-8 无 BOM；否则 `shutil.copyfile` 二进制复制；建目录失败**整批失败**并返回每轨原因 `"无法创建工作目录：%s"`，单轨失败只记 `(track.name, str(exc))` 并继续；返回克隆后的 `SubTrack` 列表（**不走 `_UTF8_CACHE`**）。

### B.4 媒体探测

23. `probe_many(ffprobe, paths, workers=4, on_result=None, cancel_event=None)`（`610`）：`workers = max(1, min(8, int(workers)))`；`ThreadPoolExecutor` + `as_completed`；取消时对所有 future `cancel()` 并 break；单文件异常、回调异常、线程池异常全部吞掉；空工具/空列表返回 `{}`。
24. `probe_subtitle(ffprobe, path, timeout=20)`（`647`）：工具缺失 → `(True, "")` 按可用；文件不存在 → `(False, "文件不存在")`；大小为 0 → `(False, "文件为空")`；`getsize` 异常 → `(False, "无法读取")`；命令 `ffprobe -v error -select_streams s -show_entries stream=index,codec_name -of csv=p=0 <path>`；进程异常/超时 → `(True, "校验失败（按可用处理）：%s")`；返回码非 0 或输出空 → 取 stderr 最后一行前 80 字符，无内容则 `"没有可识别的字幕流"`；成功返回 `(True, 原始 csv 输出)`。
25. `probe_streams(ffprobe, path, timeout=30)`（`680`）：命令 `ffprobe -v error -show_entries stream=index,codec_type,codec_name,width,height -show_entries format=duration,size -of json <path>`；返回 9 键 dict `duration/vstreams/astreams/sstreams/vcodec/acodec/width/height/size`；视频/音频仅第一条记录编码与宽高；`duration` 为 `None/""/"N/A"` 不转换；任何异常返回全默认值。

### B.5 输出路径与 ffmpeg 命令

26. `build_output_path(video, options, output_dir)`（`819`）：`container=="same"` 用源扩展名小写，否则 `"." + container`；`name = stem + (suffix or "") + new_ext`；`out_dir = output_dir or dirname(video)`；**若目标 abspath 等于源视频 abspath，改名 `stem + (suffix or "_sub") + new_ext`**，只检查一次；函数本身不创建输出目录。
27. `build_command(job, options, ffmpeg)`（`834`）：固定前缀
    `ffmpeg [-y] -hide_banner -loglevel error -nostdin -progress pipe:1 -i <video>`，
    随后每个可用字幕一个 `-i <sub>`。可用字幕筛选顺序：`enabled=False` **静默跳过** → `mp4 + bitmap` 记 `"MP4 不支持图形字幕（%s），已跳过"` → `hard + bitmap` 记 `"硬字幕暂不支持图形字幕（%s），已跳过"`；无可用字幕记 `"没有可用的字幕轨"`（命令仍生成）。
    `plan` 9 键：`mode/container/expected_video=1/expected_audio/expected_subs/burned_subs/vcodec/acodec`；软字幕 `expected_subs = 可用字幕数 + 原有字幕轨数`（仅 `keep_existing_subs=True`），硬字幕 `expected_subs=0`、`burned_subs = tracks_to_burn`。
    `keep_metadata=False` 时在输出路径前加 `-map_metadata -1`；**输出路径恒为命令最后一个元素**。
28. `_build_hard(...)`（`1010`）：无字幕 → `-map 0:v:0 -map 0:a? -map 0:s?` 且**不强制重编码**；有字幕 → 串接 `subtitles=filename='<basename>'` 滤镜链（多轨用 `[vs0]...[vout]` 标签，`;` 连接，`hard_multi=False` 只烧第一条）→ `-filter_complex ... -map [vout] -map 0:a?`（**丢弃原字幕轨**）→ 强制视频重编码。
29. `_build_soft(...)`（`1034`）：`-map 0:v:0 -map 0:a?`，`keep_existing_subs=True` 时追加 `-map 0:s?` 并令元数据索引从 `existing` 起；新增字幕 `-map 1:0 -map 2:0 ...`；`-c:s mov_text`（仅 `container=="mp4"`，`same` 走 `copy`）或 `-c:s copy`；每条字幕加 `-metadata:s:s:<i> language=...`、`title=...`（title 空时用语言中文名兜底）、`-disposition:s:<i>`（`default`/`0`，`forced` **覆盖** `default`）。
30. `_append_av_codec(...)`（`1065`）：硬字幕且 `vcodec=="copy"` 强制改 `libx264`；`copy` → `-c:v copy`；非 copy → `-c:v <值>`，4 种已知编码器加 `-preset <preset>`，`libx264/libx265` 加 `-crf <crf>`，`nvenc` 加 `-rc vbr -cq <crf>`，最后统一 `-pix_fmt yuv420p`；音频 `copy` → `-c:a copy`，否则 `-c:a <值>`。

### B.6 输出校验

31. `check_integrity(ffmpeg, path, timeout=60)`（`898`）：开头/结尾两次解码探测；`returncode != 0` 或 stderr 含 `prematurely/invalid data/truncat/corrupt/error while decoding` 视为异常；原因取首个含 `prematurely/invalid/truncat/corrupt/error` 的行前 70 字，否则末行 70 字，无行则 `"读取失败"`；产出最多 2 条 `"输出文件%s数据不完整或无法解码（%s）"`。工具缺失/文件不存在/进程异常均不误报。
32. `verify_output(ffprobe, output, plan, source_info=None, ffmpeg=None, deep=True, timeout=30)`（`941`）：**ffprobe 不可用直接判通过**；文件不存在 → `"输出文件不存在"`；0 字节 → `"输出文件为空（0 字节）"`；依次检查「输出中没有视频流」「字幕轨数量不符（期望 %d 条，实际 %d 条）」「源文件有 %d 条音轨，输出中没有音轨」「视频编码为 %s，预期 %s」（映射 `libx264/h264_nvenc→h264`、`libx265/hevc_nvenc→hevc`）「时长偏差较大（源 %.1f 秒，输出 %.1f 秒）」（容差 `max(2.0, src*5%)`）「输出体积（%s）明显小于源文件（%s），可能数据不完整」（**仅 copy+copy**）；`deep=True` 且给了 ffmpeg 时追加完整性检查。校验异常**不是**处理失败。

### B.7 格式化、进度与执行

33. `format_duration(seconds)`（`1090`）：`None/0/负数` → `"--:--"`；否则向下取整，`hh:mm:ss` 或 `mm:ss`。
34. `format_size(num)`（`1102`）：`None/0` → `"-"`；`B/KB/MB/GB/TB`，`B` 用整数，其余 `"%.2f %s"`。
35. `_popen_kwargs()`（`1115`）：`stdout=PIPE, stderr=PIPE, stdin=DEVNULL, text=True, encoding="utf-8", errors="replace", bufsize=1`，Windows 加 `CREATE_NO_WINDOW`。
36. `ProgressState`（`1125`）：`feed()` 解析 `out_time_us`（`/1e6`）、`out_time_ms`（`/1e3`）、`out_time`（仅三段 `HH:MM:SS`）、`speed`（去尾部 `x`，解析失败置 `0.0`）；其它 key 忽略；`percent()` 上限 100、时长无效返回 0；`eta()` 需 `speed>0 且 duration>position`，否则 `None`。
37. `run_ffmpeg(cmd, duration, on_progress, cancel_event, log_lines, max_log=40, cwd=None)`（`1173`）：`Popen` 失败返回 `(-1, str(exc))`；守护线程读 stderr 到环形缓冲（40 行）；主循环读 stdout 解析进度并按 **0.25 秒节流**回调 `(percent, speed, eta)`；取消时 `proc.terminate()` 并 break；读取异常时 `proc.kill()`；finally 关闭 stdout、`reader.join(timeout=5)`；stderr 追加给 `log_lines`；`error_text` 取**末 8 行**拼接。硬字幕由 GUI 传 `cwd=hard_dir` 配合纯 ASCII 字幕名。

### C.3 开始处理流程与所有前置校验（`start`）

按顺序：

1. 已在运行 → 返回。
2. `ffmpeg` 为空 → 错误弹窗 `未找到 ffmpeg，请先手动指定。`
3. `jobs` 为空 → 提示 `请先添加视频文件。`
4. `_collect_options()`：读取全部界面值；`crf = int(float(...))` 失败回退 `20`；`workers = max(1, min(4, int(float(...))))` 失败回退 `1`；`output_dir` 为空返回 `None`；`hard + vcodec=copy` 时日志 `提示：硬字幕需要重新编码视频，已强制使用 libx264。` 并改 `libx264`。
5. `options is None` → 静默返回（**原版缺陷**：后面第 1218 行的 `请先选择输出目录。` 提示不可达）。
6. `hard` 且能力检测显示缺 `libass` → 确认框 `当前 ffmpeg 未编译 libass，硬字幕（烧录）可能无法工作。\n仍要继续吗？`，否则返回。
7. `output_dir` 为空 → 提示（见上，不可达）。
8. `_ensure_probed()` 同步补齐所有 `info` 为空的任务（状态 `正在读取媒体信息（%d 个）…`）。
9. `_drop_invalid_subs()` 并发校验全部启用字幕，剔除无效轨：日志 `[跳过] %s：字幕 %s 无法识别（%s）`，收尾 `已剔除 %d 个无效字幕文件，其余照常处理`。

11. 重置每个任务状态、按 `build_output_path` 计算输出路径；总进度条 `maximum=任务数`。
12. 状态 `开始处理 %d 个视频...`；日志分隔线 + `开始处理：%d 个视频，容器=%s，方式=%s，输出=%s`。

- 读入时机：`App.__init__` → `core.load_config()`；`ffmpeg/ffprobe` 优先取配置，再回退自动定位。
- 写出时机：`choose_ffmpeg`、`on_close` 两处。
- 全部键（19 个）：`ffmpeg, ffprobe, container, mode, vcodec, acodec, crf, preset, workers, suffix, outdir, keep_existing_subs, keep_metadata, convert_encoding, hard_multi, verify, threshold, recursive, last_dir`。
- **`overwrite` 不持久化**；`crf / workers / threshold` 以**字符串**写入（来自 Tk `StringVar`）；`keep_* / convert_encoding / hard_multi / verify / recursive` 为布尔；读回时布尔用 `bool(cfg[k])`，`crf/workers/threshold` 用 `str()`。

## F. 边界行为全表（35 项）

| # | 场景 | 行为 |
| --- | --- | --- |
| 1 | 输出与源文件同名 | 自动改用 `_sub`（或自定义 suffix）后缀，绝不覆盖源文件，只检查一次 |
| 2 | 输出目录不存在 | `build_output_path` 不创建；GUI 在 `start` 里 `os.makedirs(..., exist_ok=True)` |
| 3 | 空 suffix / 自定义 suffix | 直接拼接，不加分隔符 |
| 4 | `overwrite=False` | 命令不加 `-y`；配合 `-nostdin`，同名输出直接失败而非交互询问 |
| 5 | 时长 0 / None | `format_duration` → `--:--`；`percent` → 0；`eta` → None；时长校验跳过 |
| 6 | 空列表 | 探测返回 `{}`；匹配 mapping 全空、字幕全进 unmatched；构建命令仍完整生成并提示无可用字幕 |
| 7 | 非 UTF-8 字幕 | BOM → 严格 UTF-8 → 候选打分 → 转 UTF-8 无 BOM 临时文件 |
| 8 | UTF-8 BOM | 识别 `utf-8-sig`，输出临时文件去 BOM |
| 9 | 无 BOM UTF-16 / UTF-32 | NUL 阈值 + 偶奇位零比启发式判 BE/LE |
| 10 | MP4 + bitmap 字幕 | 跳过该轨并提示；`-c:s mov_text` |
| 11 | 硬字幕多轨 | `hard_multi=True` 串接滤镜链；`False` 只烧第一条（其余静默丢弃） |
| 12 | 保留原有字幕轨 | 仅软字幕生效；`-map 0:s?` + 元数据索引偏移；硬字幕恒丢弃 |
| 13 | ffmpeg/ffprobe 找不到 | 能力全 False、版本空、探测返回默认、字幕校验「按可用」、输出校验「直接通过」；命令仍构建但执行返回 `(-1, ...)` |
| 14 | 子进程超时 | 能力/版本/探测/校验各自超时吞掉，不误报；`run_ffmpeg` 本身无总超时，靠取消 |
| 15 | 进程被终止 | 取消 `terminate()`、异常 `kill()`；仍走 `wait()` 与末 8 行错误文本 |
| 16 | 字幕路径含中文/冒号/反斜杠 | 硬字幕先复制为 `hardsub_N.ext` 纯 ASCII 名 + `cwd` 工作目录 |
| 17 | 字幕文件空/不存在/无字幕流 | 分别返回 `文件不存在` / `文件为空` / `没有可识别的字幕流` 等 |
| 18 | 输出 0 字节 / 截断 | 0 字节判失败；`-sseof -2 -t 2` 读尾部 + 关键字检测 |
| 19 | 时长/体积偏差 | 容差 `max(2s, 5%)`；体积仅纯封装检查 |
| 20 | `container="same"` | 用源扩展名小写，但仍用 `-c:s copy`（即使源是 MP4） |
| 21 | 硬字幕 + `vcodec=copy` | 强制 `libx264`，但 `plan.vcodec` 仍记 `copy`，故不校验硬字幕编码 |
| 22 | 未知编码器 | 只加 `-c:v <值> -pix_fmt yuv420p`，不加 preset/crf |
| 23 | `forced` 与 `default` 同真 | `forced` 覆盖 `default` |
| 24 | `title` 为空 | 用语言中文名兜底；未知语言不写 title |
| 25 | 隐藏目录 / 非递归 | 递归时排除 `.` 开头的**目录**（隐藏文件不排除）；非递归只取顶层文件 |
| 26 | 重复路径 | 视频/字幕分别按 abspath 去重；`skipped` 不去重 |
| 27 | 相似度短词/包含 | 空串 0；相等 1；短词包含 0；包含得分恒 >= 默认阈值 |
| 28 | 一对一约束 / 未匹配 | 已有字幕则放弃该字幕（不找次优），落 `unmatched` 且保持原顺序 |
| 29 | 语言标记 | 规范化时剔除，语言本身不参与打分；语言码单独用于轨道元数据 |
| 30 | BOM 顺序 | UTF-32 LE 必须早于 UTF-16 LE 判断 |
| 31 | 转码缓存 | key 含临时目录；只缓存生成临时文件的结果；每轮结束清空 |
| 32 | 进度/错误流 | `-progress pipe:1` 走 stdout，stderr 只含错误；40 行环形缓冲、末 8 行做错误文本 |
| 33 | 进度字段容错 | `out_time` 非三段忽略；`speed` 解析失败归零（eta 变 None）；其它 key 忽略 |
| 34 | `verify_ok` 三态 | 未校验 / 通过 / 异常 |
| 35 | `convert_encoding` 等字段 | `Options` 内定义但 core 不消费，由 GUI 决定是否调用 |

## G. 构建 / 运行 / 打包（原版）

- `启动.bat`：清除 `PYTHONPATH`/`PYTHONHOME`，查找可用 Python + tkinter，双击启动。
- `调试启动.bat`：保留控制台输出。
- `打包成exe.py`：PyInstaller `--onefile --windowed --name SubtitleMerger`，内嵌 `app.ico` 与 `vendor/sv_ttk`，**不内嵌 ffmpeg**（体积考量）。
- `dragdrop.py`：`ctypes` 注册 `WM_DROPFILES`（`0x0233`）、`DragAcceptFiles`、`DragQueryFileW`，窗口句柄由 `fluent.get_root_hwnd` 提供。
- `fluent.py`：`apply_theme`（sv-ttk 浅色主题）、`apply_scaling`、`enable_dpi_awareness`、`apply_window_effects(rounded=True, mica=False)`、自绘 `Card / Button / ProgressBar / HeroButton / DropZone / Pill`。
- `vendor/sv_ttk/`：随仓库附带的 Sun Valley ttk 主题（Tcl 脚本 + 精灵图）。
- `_selftest/`：自检样本（中文/日文/GBK/图形字幕），README 中列为可直接拖入试用的素材。
- `README.md`：功能、使用、软硬字幕差异、匹配规则、编码处理、输出校验、性能、打包、结构、FAQ。

> 已知原版缺陷（重构时按「等价保留」或「显式修正并说明」处理，见 [04 · 替代方案与交互差异](04-替代方案与交互差异.md)）：
> ① `start()` 中「请先选择输出目录」提示不可达；② 字幕对话框双击移除绑定漏写调用；
> ③ `SubTrack.enabled` 无 UI 入口（提示文案却写「勾选要合并的字幕」）；④ README FAQ 写「浏览」而按钮实际是「更改」；
> ⑤ `var_overwrite` 不持久化；⑥ `container="same"` + 源为 MP4 时仍用 `-c:s copy`。
